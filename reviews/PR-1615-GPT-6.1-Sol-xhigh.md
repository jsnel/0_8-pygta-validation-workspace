**Findings**

1. **Blocking — older parameter histories silently restore incorrect values.** [parameters.py:256](C:/src/0_8-pygta-validation-workspace/temp/pyglotaran-staging-dev/pyglotaran/glotaran/parameter/parameters.py:256)

A history written using the base implementation for a non-negative parameter equal to `10` restores as `2.302585092994046` at head. Values below one can restore as negative values. This affects earlier saved histories used to seed fits.

2. **Blocking — a failed overwrite can destroy the previous complete export.** [export.py:122](C:/src/0_8-pygta-validation-workspace/temp/pyglotaran-staging-dev/pyglotaran/glotaran/project/export.py:122)  
   The existing export is deleted before the replacement directory is renamed into place. Injecting `PermissionError` at that rename removed the previous export and left the temporary directory behind. An interruption in this interval has the same loss window.  
   **Fix:** retain a recoverable backup until publication succeeds, restore it on failure, and handle final publication errors.

3. **Should fix — concurrent exports in one process delete each other’s temporary files.** [export.py:96](C:/src/0_8-pygta-validation-workspace/temp/pyglotaran-staging-dev/pyglotaran/glotaran/project/export.py:96)  
   Temporary names contain only the destination and PID. With two calls targeting the same name, the second call failed because the temporary directory existed, then its cleanup deleted the first call’s completed files. Both exports failed.  
   **Fix:** claim unique temporary directories and coordinate publication to the shared destination.

4. **Should fix — disabling an optimizer tolerance no longer works.** [info.py:41](C:/src/0_8-pygta-validation-workspace/temp/pyglotaran-staging-dev/pyglotaran/glotaran/optimization/info.py:41)

   **Fix:** accept `float | None` and preserve null tolerances through serialization and recompute.
